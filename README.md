# Nix setup (NixOS + macOS)

One flake, built from [NIX_SETUP.md](NIX_SETUP.md), that sets up:

- **NixOS**: Hyprland, Waybar, Rofi, Foot, Nautilus, all the software, Catppuccin Dark
- **macOS** (nix-darwin): Aerospace, JankyBorders, SketchyBar, Karabiner Hyper key, Raycast, Ghostty, Homebrew casks, Finder/Dock settings, Catppuccin Dark

Both machines share the same shell, git, editors, CLI tools and themes through Home Manager.

## Layout

```
flake.nix              entry point: two machines + reusable modules
settings.nix           your name, e-mail, hostnames, time zone  <- edit first
lib/                   helpers that assemble the machines
modules/
  options.nix          shared `dotfiles.*` options (user, software groups)
  palette.nix          Catppuccin Dark colors, used by every themed app
  home/                Home Manager, macOS + Linux: zsh, git, nvim, CLI tools, themes
    linux/             Hyprland, Waybar, Rofi, Foot, GTK, lock/idle
    darwin/            Karabiner, Ghostty, SketchyBar
  nixos/
    core.nix           nix settings, time zone, user, fonts
    software.nix       apps + services (Docker, Postgres, Redis, Tailscale, ...)
    desktop.nix        Hyprland session, greetd, audio, bluetooth
  darwin/
    system.nix         macOS defaults (Dock, Finder, desktop, menu bar)
    homebrew.nix       casks and App Store apps
    services.nix       Aerospace, JankyBorders, SketchyBar, Postgres, Redis, Try Omarchy
hosts/                 per-machine bits (NixOS hardware config goes here)
pkgs/bun-1_4.nix       Bun pinned to 1.4.x
pkgs/go-1_27.nix       Go pinned to 1.27.x
nvim/ helix/ zed/ ...  raw config files the modules link into place
```

`hypr/` is the Omarchy-flavored Hyprland config and isn't used by this flake.
The NixOS Hyprland config is generated by `modules/home/linux/hyprland.nix`.

> **Flakes only see files tracked by git.** After adding or renaming a file,
> `git add` it before rebuilding, or Nix will act as if it doesn't exist.

## Fresh install: NixOS

1. Install NixOS from the official ISO (any desktop choice; this flake replaces it).
2. Get the repo and this machine's hardware config:
   ```sh
   nix-shell -p git
   git clone https://github.com/owenwexler/nix-config ~/nix-config
   cp /etc/nixos/hardware-configuration.nix ~/nix-config/hosts/nixos/
   git -C ~/nix-config add hosts/nixos/hardware-configuration.nix
   ```
3. Check `settings.nix` (hostname, `macKeyboard` for Apple keyboards, and `system`:
   `aarch64-linux` for the Parallels VM on Apple Silicon, `x86_64-linux` on Intel/AMD).
4. Switch:
   ```sh
   sudo nixos-rebuild switch --flake ~/nix-config#nixos \
     --option experimental-features 'nix-command flakes'
   ```
5. Reboot. Log in at the text greeter; Hyprland starts.

After that: `sudo nixos-rebuild switch --flake ~/nix-config#nixos`.

**Unfree and x86-only apps.** Unfree software (Zoom, Slack, VS Code...) is allowed everywhere:
the system, Home Manager, and ad-hoc `nix-shell -p` / `nix-env` (plus `nix run`/`nix shell`
with `--impure`). Some apps only ship x86_64 Linux builds, so on ARM (`aarch64-linux`) they're
left out instead of failing the build, and the switch prints a warning naming them. As of
writing that's Zoom, Slack, Spotify, Dropbox, NordVPN, Android Studio, DaVinci Resolve and
Steam. Their web versions work in Chromium.

**One-time steps on NixOS**
- `sudo tailscale up`, `nordvpn login`, sign in to 1Password, Dropbox (`dropbox` once).
- Sunshine streaming host: `systemctl --user start sunshine`, then pair at https://localhost:47990.

## Fresh install: macOS

1. Sign in to the App Store (Xcode and DaVinci Resolve install from it).
2. Install Nix: `curl -fsSL https://install.determinate.systems/nix | sh -s -- install`
3. Get the repo and switch:
   ```sh
   git clone https://github.com/owenwexler/nix-config ~/nix-config
   sudo nix run nix-darwin -- switch --flake ~/nix-config#macbook
   ```
   The first run installs Homebrew and every cask, so it takes a while.

After that: `sudo darwin-rebuild switch --flake ~/dotfiles/nix#macbook`.

**One-time steps on macOS** (Apple doesn't allow these to be scripted)
- **Karabiner-Elements**: open it, allow the driver extension and Input Monitoring.
- **Aerospace, Raycast, Ghostty**: allow Accessibility when asked.
- **Raycast** settings: turn off Window Management and Clipboard History. Spotlight's
  Cmd+Space is already off; give Raycast Cmd+Space or Hyper+D (Hyper+D also works through Aerospace).
- **Finder sidebar**: keep only Downloads, Documents, Home, Pictures, Movies, Applications
  (Finder > Settings > Sidebar). Recent tags are already off.
- **Wallpaper**: System Settings > Wallpaper > pick the Earth/space set and turn on rotation.
- **Liquid Glass**: System Settings > Appearance > Liquid Glass > **Tinted**. The switch already
  turns off "Tint window background with wallpaper color" and turns on Accessibility > Display >
  Reduce Transparency. If the switch warns that it couldn't set Reduce Transparency, turn it on
  by hand, or give your terminal Full Disk Access and re-run the switch.
- **Stats**: open once, enable the modules you want and "Start at login".
- **Xcode**: `sudo xcodebuild -license accept`, then re-run the switch to fetch the iOS simulator.
- **RetroArch**: Main Menu > Online Updater > Core Downloader for the cores listed in
  `modules/nixos/software.nix` (DOSBox Pure, Beetle PSX HW, Snes9x, Nestopia, Genesis Plus GX,
  Gambatte, mGBA, melonDS DS, Citra, Mupen64Plus, Flycast, PPSSPP, MAME).
- Log in to Tailscale, Docker Desktop, NordVPN, 1Password, Dropbox.

## Keyboard

`$mod` is **Super** on NixOS and **Hyper** on macOS. Karabiner turns the physical Left
Option key into Hyper (Shift+Cmd+Ctrl+Opt) and Caps Lock into Option.

| Keys | NixOS | macOS |
|---|---|---|
| $mod+D | Rofi | Raycast |
| $mod+Enter | Foot | Ghostty |
| $mod+B | Chromium | Chromium |
| $mod+E | Nautilus | Finder (Home) |
| $mod+P | virt-manager | Parallels |
| $mod+O | — | Try Omarchy |
| $mod+H/J/K/L | focus | focus |
| $mod+Shift+H/J/K/L | move window | move window |
| $mod+1..9 / +Shift | workspace / move to it | same |
| $mod+Tab | last workspace | last workspace |

Hyper already includes Shift, so on its own macOS can't tell $mod+Shift+H from $mod+H.
Karabiner tracks the physical Shift key and sends Hyper+Shift+key as Cmd+Ctrl+Opt+key,
which Aerospace binds separately. See `modules/home/darwin/karabiner.nix`.

## Using the modules elsewhere (Nixarchy or a custom NixOS scaffold)

The software is split out from the desktop, so it can sit on top of
[Nixarchy](https://github.com/olafkfreund/nixarchy), which brings its own Hyprland:

```nix
# in your flake inputs
dotfiles.url = "github:owenwexler/dotfiles?dir=nix";

# in your NixOS configuration
imports = [
  inputs.nixarchy.nixosModules.nixarchy
  inputs.dotfiles.nixosModules.software   # apps + services, no desktop
];
programs.nixarchy.enable = true;
dotfiles.user = { name = "owenwexler"; fullName = "Owen Wexler"; email = "you@example.com"; };

home-manager.users.owenwexler = {
  imports = [
    inputs.nixarchy.homeManagerModules.nixarchy
    inputs.dotfiles.homeModules.common      # shell, git, nvim, CLI tools, themes
  ];
  programs.nixarchy.enable = true;
  dotfiles.user = { name = "owenwexler"; fullName = "Owen Wexler"; email = "you@example.com"; };
};
```

`nixosModules.software` (and `darwinModules.default`) allow unfree packages and default
`home-manager.useGlobalPkgs` to true, so Home Manager uses the same package set. If your
config sets `useGlobalPkgs = false`, also set `nixpkgs.config.allowUnfree = true` inside
`home-manager.users.<you>`. If it passes in its own `nixpkgs.pkgs`, allow unfree where
that package set is created.

Exports: `nixosModules.{software,core,desktop,default}`, `homeModules.{common,hyprland,darwin}`,
`darwinModules.default`, `overlays.default` (adds `bun_1_4` and `go_1_27`).

Software groups can be switched off per machine, e.g. `dotfiles.software.gaming = false;`
(groups: `gaming`, `gameDev`, `videoEditing`, `mobileDev`, `kotlinDev`, `remoteGui`,
`virtualMachines`, `ai`).

## Substitutions

Where something in the spec doesn't exist on one platform, this is what's used instead:

| Spec | NixOS | macOS |
|---|---|---|
| Stickybar | — | SketchyBar (no app called Stickybar exists; your dotfiles had a SketchyBar config) |
| TablePlus | DBeaver | TablePlus |
| Parallels / UTM | QEMU/KVM + virt-manager, quickemu | Parallels, UTM |
| Try Omarchy | — (you're on Linux) | Try Omarchy (installed from GitHub releases) |
| Waypipe | Waypipe | XQuartz (`ssh -X`) |
| FreeRDP + Remmina + TigerVNC | all three + wayvnc | Windows App + TigerVNC Viewer |
| Kdenlive, Shotcut | both | — (Linux-only per spec) |
| Adobe Creative Cloud | — (no Linux version) | Creative Cloud |
| Docker | Docker service + compose | Docker Desktop |
| sshfs | sshfs | macFUSE + sshfs-mac |
| Ollama | `services.ollama` | Ollama app |
| IntelliJ IDEA CE | IntelliJ IDEA (CE was folded into it) | IntelliJ IDEA CE |
| 3DS | Citra core + Azahar | Citra core |

**Installed outside Nix** on first switch (re-run the switch if a download fails):
NVM, the npm globals (`lite-server http-server nodemon license gitconfig` into `~/.npm-global`),
the Rust stable toolchain (via rustup), Grok Build (xAI's install script).

**Bun** is pinned to 1.4.3 in `pkgs/bun-1_4.nix`; the file explains how to bump it.
